## About

FigureLab provides a focused browser workspace for composing scientific figures. Researchers can combine image panels, add annotations, and prepare polished layouts without going through a conventional software installation.

The application is packaged as one HTML file and can be used offline after it has been opened locally. Templates, measurement features, and session management support more involved layouts while making it straightforward to save, reopen, and refine ongoing work.

---

## Key Features

- Create scientific and publication-focused figure layouts in a web browser
- Work from a single HTML file without a traditional installation
- Continue working offline after the tool has been opened
- Organize panels with grid-based layouts and reusable templates
- Add panel labels and scale bars for clearer presentation
- Crop and adjust images within the figure workspace
- Mark up figures with annotations and measurement tools
- Export completed figures in multiple formats
- Save and reload sessions for later editing
- Produce captions to support figure documentation

## Workflow

To assemble a figure:

1. Launch FigureLab in a modern web browser.
2. Select a template or begin with an empty canvas.
3. Insert image panels and position them using the grid layout.
4. Crop or modify the images where necessary.
5. Apply labels, scale bars, annotations, and measurements.
6. Create a caption when accompanying figure text is needed.
7. Export the result using the desired format.
8. Save the session for future revisions.

Existing sessions can also be loaded when producing recurring figure types, allowing you to replace changed panels or update annotations without rebuilding the layout.

## Frequently Asked Questions

**Is an installation required?**  
No. FigureLab is intended to run by opening its single HTML file in a web browser.

**Does FigureLab work without an internet connection?**  
Yes. Once the file is available locally, the workflow supports offline use.

**Where should I keep saved sessions?**  
Session storage depends on your local browser and file-management workflow. Save session files somewhere that will remain accessible when you return to the project.

**What should I check if export results are unexpected?**  
Verify the chosen export format, confirm that your browser is up to date, and review the canvas contents. You can reopen a saved session to correct the layout or annotations and export again.
